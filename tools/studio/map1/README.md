# Map 1: Stable Simulation expansion (working copy only)

The owner approved the two-map direction on 2026-11-13; the decision record is vault draft PR #15. This folder builds the **Map 1 Stable Simulation** expansion in a separately saved **working copy**. It is never used on the authoritative `Place1.rbxl`.

## What it builds
The existing Containment Hall and reactor become the **hub**. Three boss-ready wings are added outside the hall wall (±414), under `Workspace.WORLD_EXE.Map.Map1Expansion`; every part carries the attribute `Map1Expansion = <sector>`.

| Sector | Centre | Boss floor | Objective space | Routes |
|---|---|---|---|---|
| ContainmentVault (N) | (0, 0, −598) | 160×204 hall, Y24 balconies, dais, pods | Antechamber forecourt | Ground corridor via the Archive; Y24 bridge from the outer ring |
| TestingPit (W) | (−620, −24, 32) | Pit about 188 across, tiers at −18/−12/−6, Y24 gantry | Test Control deck | Ground corridor via the Yard (with a nook); Y24 bridge stacked over it |
| Foundry (E) | (600, 0, −20) | 180×180, catwalk rings at Y24 and Y48, Y72 ledges | Y24 Control Gallery | Ground corridor via SkyBase (with a nook); Y24 bridge |

The build also adds a calm non-collidable backdrop of distant towers, hub-side portal frames and gatehouses. Boss floors carry the `BossSectorFloor` attribute, and each sector has a `BossSector_<Name>_Bounds` volume. These are data only: no boss AI.

## Scripts (run in Studio Edit mode, in this order)
| File | Purpose |
|---|---|
| `0_isolate_sprint_exterior.luau` | Moves the ENV_SPRINT2 exterior (West Rift, slabs, volume) to `ServerStorage.Map1_Isolated`. Set `_G.MAP1_ISOLATE_MODE = "restore"` to undo. |
| `1_build_expansion.luau` | Idempotent build, generated by `gen_expansion.js` from `build_expansion_template.luau`. It also cuts the hall openings and moves the cut originals aside. |
| `2_set_bounds.luau` | Working-copy-only edit of the Config ArenaBounds source. `restore` mode undoes it. |
| `3_measure_area.luau`, `lib_walkgraph.luau` | Walk-graph area and reachability measurement. |
| `4_script_hashes.luau` | Hashes every script source (preservation check). |
| `5_check_map1.luau` | K1 overlaps, K2 spawns, K3 markers and drone links, K4 boss-floor connectivity with route redundancy, K5 rails, drops and ramps, K6 script preservation, K7 structure and budget report. |
| `6_walk_tests_server.luau` | Solo Play `MoveTo` route timings. |
| `9_remove_expansion.luau` | Removes only what it recognises and restores the cut and moved originals. |

The full list of existing objects that change, and the proposed `Config.luau` change, are in `docs/maps/map1/CHANGED_OBJECTS.md`.
