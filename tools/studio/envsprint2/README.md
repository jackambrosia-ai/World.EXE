## Exterior replacement (visual recovery, v1 → v2)
`node assemble.js --all` regenerates every build from the specs (deterministic; refuses if a spec fails preflight or cannot be evaluated offline):

| File | VERSION (Map attr) | Replaces | `REPLACE_EXTERIOR` | Use |
|---|---|---|---|---|
| `1_build.luau` | v1 2026-11-13 | – | false | v1 build/verify (as built; behaviour unchanged by the refactor) |
| `1_build_v2.luau` | v2 2026-11-13 | v1 exterior | **false** | v2 fresh build or verify (no-op when v2 is built); on the exact v1 state it **refuses** |
| `2_replace_exterior_v1_to_v2.luau` | v2 2026-11-13 | v1 exterior | true | swap v1 → v2 |
| `8_restore_exterior_v2_to_v1.luau` | v1 2026-11-13 | v2 exterior | true | rollback of the swap: v2 → v1 rebuilt from `exterior_spec.luau` |

Semantics (template header): a build recognises the replaceable state only if `Map.EnvSprint2` matches **exactly** (every property, attribute, tag, child, light) its own traversal plus the named old exterior and nothing else, and the Map attribute equals the old VERSION. Then it builds the new exterior off-tree, self-checks it and, in one frame, clears the attribute, destroys the old `Exterior_*` models, parents the new ones, re-checks the whole folder and sets the new VERSION. Traversal models are verified and never touched. Any other state (partial, tampered, foreign child, stray marked instance) is refused with nothing changed. If the final re-check ever fails the attribute stays cleared (audit reports an incomplete build): run `9_rollback.luau`, then a fresh build.
Studio sequence (disposable copy first): `1_build_v2` (expect refusal) → `2_replace…` → `1_build_v2` (expect "already built") → audit → `8_restore…` → `1_build.luau` (expect "already built" = exact v1) → `2_replace…` again for production. Negative tests: recolour one v1 part, or add a Folder under `Map.EnvSprint2`, then `2_replace…` must refuse.
`exterior_spec.luau` (v1) is unchanged; `exterior_spec_v2.luau` is the visual-recovery spec: Agent A's wall-scale design (rev 3), revised by the coordinator after Studio previews (rev 5). The rift was moved off the wall face into the void-band air, the slabs were moved clear of it and tilted, the rift was widened, a sparse wall grid was added, and the lights were lowered to brightness 2. It is generated by `C:\WORLD.EXE-Art\EnvSprint2\visual_recovery\agentA\gen_spec_v2.js` (kept outside the repo because it depends on the local geometry export).

## Roles (collidable parts, SprintTraversal only; exactly one per part)
- `WalkSurface`: level, unrotated Block ≥ 4×4 in bounds, joined flush to another floor (ENV_SLICE1 rule).
- `EdgeRail`: unrotated Block ≥ 4 high on a sprint WalkSurface edge that faces the void (C13).
- `JumpStep` (new, Agent C): level, unrotated Block ≥ 4×4 in bounds; jump links rise ≤ 6.5 and gap ≤ min(6, 9 − rise) across a shared edge ≥ 4; each step group links two existing floors; no void (floor ≤ 40 below every corner and the centre); take-off headroom 12 studs over the 2-stud band plus gap (C6j); C6s above each step.

Decorative parts: CanCollide/CanQuery/CanTouch/CastShadow false. Material ForceField is allowed only in SprintExterior (visual-recovery brief); Air/Water never. Lights: PointLight/SpotLight, SprintExterior only, Shadows false. Streaming: Traversal Default, Exterior Atomic.

## Spec row format
`{ name, size, position, {r,g,b}, material, role|nil, orientation(deg)|nil, extra|nil }`; `extra` keys: `shape` (Block/Wedge/Cylinder/Ball), `class` (Part/WedgePart/CornerWedgePart), `transparency` [0,1), `reservedUse` (string → `ReservedUse` attribute), `light` `{ class, range ≤ 60, brightness ≤ 10, color, angle?, face? }`. Group keys: `model`, `category`, `parts`, optional `anchors = { { name, position, size } }`. Reserved names (audit/gameplay meanings) are refused.

Upgrading: `VERSION` now comes from the assembler (`--version`, or the `PRESETS` table for `--all`); bump it on every geometry change. Exterior-only changes use a replace build (above); anything else: `9_rollback.luau`, then the new build.
