# Phase 8 — UI, visual polish, and accessibility

Use `docs/04_UI_AND_ART_DIRECTION.md` and the user's WORLD.EXE visual reference board as art direction. Reproduce the visual language, not the reference image as a flat screenshot.

Build functional Roblox UI for:
- Main menu/lobby.
- Match HUD and stability meter.
- Active patch strip and warnings/counterplay.
- Architect patch cards and submission timer.
- Stabilizer objectives and interaction progress.
- Abilities/cooldowns.
- Results.
- Basic Patch Archive.
- Settings for reduced screen shake/flashing.

Use navy, cyan, violet, restrained amber, green success, and sparing red danger. Ensure text/shape/icon reinforce color. Support keyboard, controller, mouse, and touch as applicable. Check common aspect ratios. Keep VFX bounded and client-side where possible. Test that UI never hides critical gameplay and warning information remains available without audio.
